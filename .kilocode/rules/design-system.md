# 202f Academy — внедрение редизайна (инструкция для Kilo Code)

Положи файл в `.kilocode/rules/design-system.md` в корне проекта, чтобы агент читал его в каждой задаче.

## Цель
Переоформить всё приложение (визуал и навигацию) в новой системе. **Логику, данные, тексты, маршруты и хранение прогресса не менять.** Менять только вид и структуру интерфейса.

## Жёсткие правила
1. Никакого выдуманного контента. Все тексты, цифры, названия берутся из текущего кода и данных приложения. Если нужного текста нет, оставь существующий.
2. Не удалять и не переименовывать разделы, роуты и функции. Только перенести пункты меню (см. «Навигация»).
3. Не добавлять новых зависимостей без необходимости. Шрифты подключить через стандартный механизм текущего стека.
4. Работай по шагам (см. «Порядок работы»), после каждого шага приложение должно собираться и открываться.
5. Логотип «202» (парень в кепке) оставить как есть, только поменять цвет надписи.
6. Определи стек (React/Next/Vite и т.д.) по коду и следуй его соглашениям.

Каждой категории контента (латте-арт, V60, Kalita, Aeropress, Cold brew и т.д.; вкусы) закрепи один акцентный цвет и используй его везде одинаково. Цвет не декор, а метка категории. Не различай состояния только цветом.

### Типографика
- Заголовки и логотип: **Unbounded** 800, верхний регистр. Заголовок экрана 28px, название карточки 25px, название плитки 15px, логотип 17px, line-height 1.15.
- Текст и интерфейс: **Manrope** 500/700, 14–15px, line-height 1.4. Минимум 12px.
- Кикеры (малые метки над заголовком): Manrope 700, 12px, letter-spacing 2px, верхний регистр.
- Фолбэк: `'Unbounded', Manrope, sans-serif`. Для кириллицы подключить оба шрифта с поддержкой cyrillic.

### Форма и отступы
- Крупные карточки: радиус 32px, padding 20px.
- Плитки: радиус 28px. Кнопки: радиус 26px, высота 52px. Круглые кнопки: 44–48px.
- Чипы: высота 44px, радиус 22px, padding 0 20px.
- Отступ экрана 20px, зазор между блоками 12px.
- Минимальная зона нажатия 44×44px.

### Тени и состояния
- **Нажатие** (`:active`, на карточках, плитках, кнопках): `box-shadow: inset 3px 3px 6px rgba(0,0,0,.4)` и `transform: scale(.98)`.
- **Выбранная плитка/карточка**: `box-shadow: inset -5px -5px 10px rgba(0,0,0,.7)`. Без обводки (outline/border).
- Внешние тени на тёмном фоне делать с оттенком из палитры (тёмно-красный или васильково-синий, например `rgba(91,69,240,.7)`), чёрные там не видны.
- Переходы: `box-shadow .2s ease`, `transform .35s cubic-bezier(.34,1.56,.64,1)` (пружина).
- Уважать `prefers-reduced-motion`: отключать пружину и масштаб.

## Навигация
- **Шапка** на каждом экране: слева круглая кнопка бургер-меню (44px), по центру логотип «202F ACADEMY» («202F» жёлтым), справа круглая кнопка-аватар профиля (фиолетовая).
- **Нижняя панель**: плавающая «таблетка» (отступ 20px от краёв и низа, высота 68px, радиус 34px, фон `--surface-light`), 5 иконок без подписей: **Путь, ТТК, Тесты, Методики, Вкусы**. Активная иконка: чёрный круг 52px, иконка цвета `--lime`. У каждой кнопки `aria-label` и `aria-current="page"` у активной.
- **Бургер-меню** (выезжает слева): Смена, Дисциплина и остальное, что не вошло в панель.
- **Профиль**: через аватар в шапке.
- Контент экранов должен иметь нижний отступ не меньше высоты панели + 20px, чтобы ничего не пряталось под ней.
- Иконки: линейные, stroke 2, скруглённые концы, 24px. Для «Пути» маршрут (две точки и извилистая линия), для ТТК галочка в круге, Тесты звезда, Методики книга, Вкусы глобус.

## Шаблон экрана
Кикер (по желанию) → заголовок-плакат → строка поиска/фильтр (если есть на экране) → чипы категорий (горизонтальный скролл) → ведущая карточка → список карточек.
- Ведущая карточка: цветной фон категории, тег категории, заголовок, описание, чипы формата и время, чёрная кнопка 52px.
- Список: карточки с цветом категории или светлые.
- Статистика (если есть): светлая карточка, столбцы серые, выбранный чёрный.

## Компоненты (сделать переиспользуемыми)
`AppHeader`, `BottomPill`, `BurgerDrawer`, `Chip`, `ChipRow`, `FeaturedCard`, `Card`, `Tile` (сетка 2 колонки: номер сверху, название снизу), `DetailCard` (светлая, блоки с кикерами), `PrimaryButton`, `IconButton`.
Для каждого: состояния default, active/pressed, selected, disabled, focus-visible (видимое кольцо фокуса не обводкой выбора, а `outline` с `--lime`, только при навигации с клавиатуры).

## Порядок работы
1. Токены и шрифты, глобальные стили.
2. `AppHeader`, `BottomPill`, `BurgerDrawer`, перенос пунктов меню. Проверить, что все 8 разделов доступны.
3. Базовые компоненты (Chip, Card, FeaturedCard, Tile, DetailCard, кнопки).
4. Экраны по очереди: Библиотека (Методики), Вкусы, Путь, ТТК, Тесты, Смена, Дисциплина, Профиль. Для каждого сохрани существующую структуру данных и тексты.
5. Состояния нажатия и выбора, анимации, reduced-motion.
6. Проверка: ширины 360, 390, 430px; контраст текста не ниже 4.5:1; ничего не обрезается (заголовки, подписи); фокус с клавиатуры; сборка без ошибок.

## Критерии приёмки
- Все разделы на месте и работают как раньше, прогресс сохраняется.
- На каждом экране шапка, нижняя панель и палитра из токенов.
- Нет текстов, которых не было в приложении.
- Нет горизонтального скролла страницы, нет налезающих друг на друга подписей.
